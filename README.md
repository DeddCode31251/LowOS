# Preview

Simple OS Simulator using HTML CSS JS, That simulate a real os.

# Technologies

**HTML CSS JAVASCRIPT** 

# Features
- readme.asm
-- You can press [ Run some assembly ] to run cpu.lab and [ Open shell ] to run the shell

- shell
-- To run any commands first click under the ```user@lowos:~$``` and type for first command to test ```help```

- cpu lab
-- A 4-register toy CPU. you can edit it and run it too. and there's a button to reset it.

- projects.c
-- its some projects that i made on github.
